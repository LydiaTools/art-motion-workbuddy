# Art Motion for WorkBuddy · v0.1.2 entry

This branch contains the lightweight, version-pinned Codex Skill entry for [Art Motion for WorkBuddy](https://github.com/LydiaTools/art-motion-workbuddy). It does not include the rendering engine.

On first use, the entry prepares the independently downloadable [v0.1.2 runtime](https://github.com/LydiaTools/art-motion-workbuddy/releases/tag/v0.1.2) in a new user-selected directory and verifies its SHA-256. The runtime is based on [huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion); the package contains the upstream license and credits.

The entry files are a snapshot of main at `064e5e469475902fcffc61ee97e321b9a8dc199f`. For project information and newer releases, visit [the main repository](https://github.com/LydiaTools/art-motion-workbuddy).
